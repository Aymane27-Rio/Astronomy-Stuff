# Cosmic Phenomena

A small multi-page website showcasing animated astronomy scenes (Solar System, Black Hole, Supernova, Pulsar, Galaxy) with educational facts.

## Quick start

- Open `index.html` directly in your browser, or run a simple local server:
  - Python 3: `python -m http.server 5500` then visit http://localhost:5500/
  - Node: `npx serve -p 5500`

## Pages

- `index.html` – landing page
- `solar-system.html`
- `black-hole.html`
- `supernova.html`
- `pulsar.html`
- `galaxy.html`

## Structure

- `assets/css/style.css` – shared styles
- `assets/js/main.js` – shared scripts (stars, info panel, transitions)
